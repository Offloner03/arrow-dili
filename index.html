Arrow Jam

Clear the arrows before time runs out!

How to Play 🎯

1. Click an arrow to remove it from the board.

2. Arrows can only move if their path is clear (not blocked by other arrows).

3. CAREFUL: If an arrow hits another, you get a -1 second penalty!

4. Clear all arrows as fast as possible. Higher levels have more complex, interlocking arrows.
